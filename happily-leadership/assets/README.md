# Happily branding

Official existing Happily smile-mark PNGs, copied without redrawing or altering pixels from the Happily-Company checkout on 26 October 2026:

- `happily-logo.png`: `public/img/icons/android-chrome-512x512.png` (512 x 512). The listing icon in both directories, the ChatGPT `logo` and the Claude plugin `icon`.
- `happily-icon.png`: `public/img/icons/apple-touch-icon-76x76.png` (76 x 76, 8,254 bytes). The ChatGPT `composerIcon`.

Each skill also carries the coin, scaled down from `happily-logo.png`, for ChatGPT's skill list: `skills/<skill>/assets/happily-icon-small.png` (64 x 64) and `happily-icon-large.png` (192 x 192), named in that skill's `agents/openai.yaml`. Claude reads only `SKILL.md` and ignores both.

The filled app icon (the coin on Happy Blue, from the iOS app) is in `docs/directory-assets/` for portals that crop to a square tile. It isn't packaged.
